## English Version

### 1. Nature of the Project

This project (`ZZMI-Mod-Manager`) is a **local file management utility**. It only performs local
filesystem operations on ZZMI / XXMI Launcher mod files: enabling, disabling, organizing,
categorizing and moving them.

This tool **does NOT**:

- modify the game client or any game binaries;
- inject code into the game process or tamper with game memory;
- bundle, contain, or distribute any game assets, textures, meshes or third-party mod content.

**All risks and consequences arising from the use of this tool are borne solely by the end user.**

### 4. Permitted Use

### 5. Your Files

The tool never deletes files. Disabling a mod only renames its folder with a `DISABLED_` prefix,
and every operation is journaled so it can be undone. Even so, you are responsible for
**backing up your own data** before use.
