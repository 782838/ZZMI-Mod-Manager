😵 连不上后台服务

界面由本地小服务器驱动, 现在收不到它的回应。最常见的原因是系统代理把 127.0.0.1 也拦截了。

  1. 确认那个黑色控制台窗口还开着 —— 关掉它程序就退出了。
  2. 如果开着代理/加速器(Clash、v2rayN、迅雷等), 把 127.0.0.1 和 localhost 加入「直连/绕过」列表, 或暂时关掉「系统代理」。
  3. 重新双击 启动ZZMI管家.bat 或 ZZMI-Mod-Manager.exe: 它会用独立窗口 + 强制绕过代理的方式打开, 基本不会再遇到这个问题。

📖 使用教程（首次必读）
  1. 申请 API 凭据：打开 https://my.telegram.org 登录 → API development tools → 填 App title / Short name（随便写）→ 拿到 api_id（数字）和 api_hash（字符串）。这是你个人的，只存本机，别分享。
  2. 代理：国内直连不通。填代理软件的本地端口，如 socks5://127.0.0.1:7890（clash）或 socks5://127.0.0.1:10808（v2ray）。打开代理软件看「本地端口 / SOCKS」。
  3. 登录验证：填 api_id / api_hash / 代理 / 手机号 → 点「发送验证码」→ Telegram 把码发到手机或桌面端 → 填进「验证码」→ 点「登录」。要两步验证密码也填进去。登录后生成本机 session，之后免验证。
  4. 导入群组：登录后，粘贴 @用户名 或 t.me/xxx（公开频道），或已加入的私有频道名 → 点「验证导入」→ 自动拉最近带附件的消息、下载 zip/ini 到下载目录（预览图可选）。

⚠️ 只爬你已加入的频道 / 作者公开频道，不碰私有无授权。只读不发送。下载只进工具自己的下载目录，不碰 Mods。
